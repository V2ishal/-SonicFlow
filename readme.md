# 🎵 Spotify Web Clone

This is a **Spotify Web Player UI Clone** built using **HTML and CSS**.  
The project focuses on creating a responsive and modern music player interface similar to Spotify.

---

## 🚀 Features

- 🎧 Sidebar navigation (Home, Search, Library)
- 📂 Playlist and Podcast section
- 🎶 Music cards (Recently Played, Trending, Featured)
- 📌 Sticky top navigation bar
- 🎵 Bottom music player UI
- 🎚️ Custom progress bar (range slider)
- 📱 Responsive design (basic media queries)

---

## 🛠️ Technologies Used

### ✅ HTML
- Semantic structure (div, h2, img, button, input)
- Layout division (sidebar, main-content, music-player)
- Font Awesome icons
- Google Fonts (Montserrat)

---

### 🎨 CSS
- Flexbox (for layout alignment)
- Responsive design using media queries
- Custom styling (colors, spacing, border-radius)
- Sticky navigation (`position: sticky`)
- Fixed music player (`position: fixed`)
- Hover effects (opacity change)
- Custom range slider styling
- Box model (margin, padding, border)
